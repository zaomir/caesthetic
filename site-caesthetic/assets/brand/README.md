# CAESTHETIC brand logos

Canonical brand kit for `caesthetic.com` (public site) and `caesthetic.co` (cold-email brand).

| File | Use |
|------|-----|
| `logo-square.png` / `logo-square.svg` | Square mark for circular avatars / round frames |
| `logo-long.png` / `logo-long.svg` | Horizontal lockup (wordmark) |
