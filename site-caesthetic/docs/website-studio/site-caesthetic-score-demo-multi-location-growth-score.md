# WEBSITE STUDIO + IMPECCABLE QA MANIFEST

## Design discovery

**DESIGN DISCOVERY:** assumptions recorded. The audience is a U.S. multi-location aesthetic-practice CMO who needs a decision in five minutes and evidence afterward. Reused the approved Clinical Editorial Intelligence system, canonical Growth Score v5 structure, public-only evidence rule and one-CTA package model. Required effects are clear protect/fix/pilot/scale decisions, explicit owner accountability and a readable comparison without turning locations into ranked businesses. Decorative dashboards, aggregate Network Scores, internal-performance claims, hidden limitations and a second report structure are prohibited.
