# CAESTHETIC audit storage

Client Growth Score audits live under `growth-score/cases/`. Technical QA and
release evidence may remain elsewhere in this directory, but they are not
client audit cases.

Historical, non-current competitive baselines live under `historical/`. They
must not be treated as active Growth Score evidence without a new approved
Research Alignment and a current-standard evidence refresh.

Start here: [`growth-score/README.md`](growth-score/README.md).
