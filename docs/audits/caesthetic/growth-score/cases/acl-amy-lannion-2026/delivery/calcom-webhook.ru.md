# Cal.com → очередь запросов на отзыв: ACL Amy

Статус: реализовано локально; развёртывание и внешнее подключение проверяются отдельно. Отправка клиентам отсутствует в этой версии.

## Контракт

Это интервенция Reputation / Reviews для текущего пакета Эми, без нового продукта или цены. Владелец кабинета — Amy Bernis; техническое сопровождение — CAESTHETIC. Пользователь поручил подготовить интеграцию 2026-09-08. Результат первого этапа — приём подписанных событий и постоянная очередь, без обращений к WAHA.

Адрес: `https://caesthetic.com/api/amy/calcom`. Версия webhook `2021-10-20`, Custom Payload выключен. Отдельный секрет хранится в GitHub Actions / Worker secrets, не в Git и не в этом документе.

События: BOOKING_CREATED, BOOKING_REQUESTED, BOOKING_RESCHEDULED, BOOKING_CANCELLED, BOOKING_REJECTED, BOOKING_UPDATED (если предлагается интерфейсом), MEETING_ENDED, BOOKING_NO_SHOW_UPDATED. Фильтр: organizer.email = amybernis@caesthetic.com и type = rdv. Частичные события связываются только с ранее принятой записью. Реальный payload аккаунта ещё не получен: проверить фильтр и поля тестовой записью.

Форма Cal.com: телефон с кодом страны; checkbox со slug `whatsapp-review-consent`, по умолчанию пустой. Текст: «J’accepte de recevoir sur WhatsApp un message après mon rendez-vous pour donner mon avis. Je peux me désinscrire en répondant STOP.» Только логическое true даёт согласие, строки и отсутствие поля не дают. Сбор контактов из почты/Google Contacts не используется.

## Что реализовано

- Проверка HMAC SHA-256 исходного тела; лимит 64 KiB; защита от слишком старого события (7 дней), неверной версии и чужой записи.
- D1: booking UID, время, имя, телефон, согласие и время его получения, статус; SHA-256 события для повторов. Без почты клиента, медицинских заметок, описания процедуры или сырого payload.
- Атомарная запись, защита от старых доставок, отдельный UID при переносе с tombstone старого UID. Частичное событие до создания записи возвращает 503 для повтора.
- Отмена/отклонение удаляет имя и телефон; отменённый UID не открывается повторно. MEETING_ENDED не доказывает посещение. Неявка блокирует дальнейшее планирование.
- Предварительное due_at = конец + 24 часа. Все записи остаются без разрешения отправки; дневное окно Europe/Paris, cooldown, STOP, подтверждение посещения и WAHA-диспетчер — следующий этап, до его включения.
- Контактные записи удаляются через 60 дней, хеши доставки через 90 дней, ежедневно в 03:17 UTC.
- Нет доступного извне списка контактов, отправляющей функции, ключей WAHA или ссылки Bebo в обработчике.

## Проверка и ограничения

Локальные тесты используют искусственные контакты. Требуются production-проверки неверной подписи, правильной подписи, повтора, отмены и переноса. HTTP 200 на ping не доказывает приём записи: чужие/неизвестные события возвращают ignored. Полный Cal.com тест подтверждает received. Live QA не отправляет WhatsApp.

До клиентского запуска: настоящий Cal.com payload и consent checkbox; отдельная WAHA-сессия Эми; учёт посещения; STOP/suppression; ограничение частоты; подтверждение доставки; настоящая Google-карточка Эми, одинаковая возможность публичного отзыва для всех. Bebo — только закрытая демонстрация. Базовый объём запросов и доля отзывов не измерены; влияние не заявляется. Отправка остаётся выключенной при любых непроверенных условиях.
