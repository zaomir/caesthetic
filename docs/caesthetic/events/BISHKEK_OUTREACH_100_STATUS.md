## Reply handling

A substantive reply changes the account from outbound to human-owned dialogue. Classify as one of:

`interested / request_information / referral / wrong_person / not_now / commercial_question / compliance_question / negative / unsubscribe / unclear`.

Do not continue automated first-touch outreach to the same company after any substantive reply.

Handoff rule:

```text
Alex / CAESTHETIC
→ qualification and relevance confirmed
→ concrete readiness to act
→ introduce Valeriia via v@caesthetic.com
```

Polite interest, routing, or a request for general information alone does not trigger the Valeriia handoff.
