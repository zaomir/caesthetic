# Шаблон: сбор кейса для публикации

**Один файл на кейс.** Заполнять все обязательные поля — незаполненные блокируют публикацию.
Кейс без подтверждающих данных не публикуется ни в каком виде.

---

## 0. Пригодность — проверить до заполнения

Кейс **не публикуется**, если:

- [ ] Нет письменного разрешения клиента на публикацию
- [ ] Кейс связан с закупкой препаратов, Toxifillers или любым supply-направлением
- [ ] В данных фигурируют пациенты клиента — имена, контакты, фото, отзывы с идентификацией
- [ ] Результаты невозможно подтвердить скриншотом, выгрузкой или публично проверяемым источником
- [ ] Вертикаль — недвижимость, салоны красоты, инфобизнес, e-commerce

**По вертикалям.** Для позиционирования в эстетической медицине кейс из недвижимости хуже, чем отсутствие кейсов: он опровергает специализацию. Кейсы из стоматологии, дерматологии и смежного здравоохранения — пригодны, публикуются с явным указанием вертикали. Всё остальное не используется.

## 6. Обязательное для публикации в США

- **Типичность результата.** Если результат нетипичен для наших клиентов — это раскрывается прямо в кейсе. Правила FTC об эндорсментах требуют либо типичности, либо явного указания, что типичный результат иной
- **Материальная связь** раскрывается, если клиент получал скидку, бесплатную работу или иное вознаграждение за согласие на публикацию
- **Никаких обещаний** повторимости результата
- Формулировки результатов — фактические, без `guaranteed`, `always`, `every client`

## 8. Как это будет опубликовано

Формат кейса на сайте — четыре блока:

**Situation** — профиль клиента, проблема, что пробовали до нас
**Approach** — что делали, достаточно подробно, чтобы было достоверно
**Results** — конкретные цифры, проценты, суммы
**Timeline** — за сколько

Плюс блок «что не сработало» и, при наличии, цитата.

Кейсы из смежных вертикалей публикуются в отдельном разделе с честным заголовком вида `Adjacent healthcare` — не смешиваются с эстетикой и не выдаются за неё.
