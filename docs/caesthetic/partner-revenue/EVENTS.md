# CPRP — мероприятия и платное участие

## 1. Две независимые оси

| Ось | Значения |
|---|---|
| Состав организаций | BILATERAL: один клиент + один audience partner; MULTIPARTY: три и более самостоятельные организации |
| Способ участия | ONLINE, IN_PERSON, HYBRID |
| Назначение | Education/Health Day, member activation, benefits launch, профессиональное demo/networking |
| Монетизация | Client organization SOW, sponsor fee, exhibitor fee, funded memberships; только договорные линии |

CAESTHETIC — организатор; не включается в число участников при выборе BILATERAL/MULTIPARTY. «Один на один» означает две организации, а не двух посетителей. Число организаций не равно размеру аудитории.

Управление и продажи event packages происходят дистанционно. Очный формат выбирается по ценности для аудитории/демонстрации; для исполнения допустимы назначенные локальные поставщики и venue team. Присутствие одного незаменимого координатора не условие существования программы.

## 2. Curated composition

Сначала фиксируем primary audience и пользу для неё, затем anchor client/partner, после — дополняющие услуги и спонсоры. Для каждого кандидата нужны role, audience fit, компетенция, contribution to agenda, conflicts/exclusivity, ожидаемый коммерческий результат и способ его измерить.

Health Day может объединить стоматологию, другие релевантные услуги, страховую и поставщика оборудования. Но supplier demo имеет смысл при доступе к клиникам/специалистам, принимающим решения о закупках; список премиальных банков сам по себе этого не доказывает. Для потребительской аудитории выбираем соответствующий формат демонстрации либо отдельную профессиональную сессию.

Клиническое участие выполняют соответствующие провайдеры в допустимом формате. Платный sponsor slot не делает продукт медицинской рекомендацией и не даёт влиять на назначения.

## 3. Продаваемый inventory

| Пакет / единица | Обязательство CAESTHETIC | Подтверждение |
|---|---|---|
| Organization package | План, набор участников, расписание, registration flow, coordination, отчёт | Исполненный runbook и принятый отчёт |
| Exhibitor/demo | Ограниченное место/время, инфраструктура, agreed audience access | Факт участия и доступных условий |
| Sponsored educational block | Обозначенное спонсорство, тема, согласованный format | Запись/материалы при разрешении |
| Distribution package | Согласованные digital placements до/после события | Placement evidence и агрегаты |
| Funded benefit inventory | Закупка/финансирование определённого количества benefits | Funding, issuance/redemption ledger |

У каждого inventory item есть capacity, price/currency/tax treatment, срок бронирования, payer, cancellation/refund/substitution, exclusivity и evidence. Пакеты не означают продажи attendee list, гарантии клиентов или присутствия неподтверждённого банка. Intro/follow-up возможны по запросу/согласию адресата.

## 4. Event P&L и управление риском расходов

Budget line содержит responsible party, committed/paid amounts, due date, cancellation exposure. Считаем:
- contracted revenue;
- cash collected;
- earned revenue по исполнению;
- direct costs и refunds;
- contribution отдельно от client patient revenue.

До необратимого расхода production budget должен иметь названное финансирование, лимит убытка и cancellation plan. Денежные обещания спонсоров не равны cash coverage. Один event SOW может включать фиксированную fee и согласованные pass-through costs, которые не раздувают Caesthetic margin.

## 5. Event workflow

Brief → подбор anchor → audience/distribution commitments → packages и состав → дистанционные договоры/депозиты → registration/eligibility test → delivery → fulfillment evidence → follow-up → settlement → repeat/stop.

На общей регистрации visitor выбирает, какому поставщику и по какой цели передать контакт. Root event/campaign отмечает источник; provider-specific enrollment ведётся отдельно. Один участник может обратиться к нескольким провайдерам, но каждый платёж принадлежит конкретному клиенту и своему attribution decision.

Клиент видит свои обращения; спонсор — выполнение пакета и разрешённые контакты, а не медицинскую воронку всех участников.

## 6. Минимальные KPI

Registration/attendance отдельно по modality; activation/benefit redemption; requests по провайдерам; event-sourced collected revenue; event-assisted pipeline без автоматической fee; paid sponsorship, refund rate, fulfillment, contribution, repeat intent и coordinator hours. Итоговый отчёт различает измеренный результат, самоотчёт партнёра и неизвестное.
