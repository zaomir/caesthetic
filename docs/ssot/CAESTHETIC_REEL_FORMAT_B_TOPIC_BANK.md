# CAESTHETIC Reel Format B Topic Bank — STOP FLAG

## 0. Status

This topic bank is registered so agents can see that a Format B topic-bank lane exists, but **production from this bank is blocked until Format B v1.1 is written and approved**.

Current visible Format B authority, `CAESTHETIC_REEL_FORMAT_B.md` v1.0, applies only to episodes that explicitly declare:

```yaml
format_system: "CAESTHETIC Reel Format B v1.0"
spec_ref: docs/ssot/CAESTHETIC_REEL_FORMAT_B.md
```

Do not treat v1.0 as permission to generate additional Format B scripts, episodes or variants from this topic bank.

## 1. Why blocked

Format B is a synthesis format. It must not become a generic long Reel template before v1.1 defines:

- topic selection criteria;
- relationship to the protected `Format A → Format A → Format A → Format B` cycle;
- claim/evidence requirements for synthesis;
- what may be reused from Format A episodes;
- Valerie/opening/avatar testing boundary;
- production cost and capacity gate;
- paid vs organic learning rule;
- registry status transitions.

## 3. Production rule

Until v1.1 exists:

- workers may read this file only as a stop flag and topic inventory;
- workers may draft Format A episodes from the underlying owner questions if the normal evidence gate passes;
- workers must not create Format B scripts, YAML episodes, Kling prompts, Valerie shot lists or production tasks from these candidates;
- any request to produce Format B from this bank must first update `CAESTHETIC_REEL_FORMAT_B.md` to v1.1 or create a separate v1.1 SSOT with founder approval.

## 4. Organic testing limit

Do not use organic performance from one or two Format B Reels to conclude that a Valerie/opening/avatar variable won. Organic cadence is too low and topics are confounded. Controlled paid distribution or another controlled test layer is required for variable isolation.
