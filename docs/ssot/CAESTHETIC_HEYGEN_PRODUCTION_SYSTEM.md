# CAESTHETIC HeyGen Production System

## 1. Purpose

HeyGen is not the final video editor for CAESTHETIC. It is the synthetic production layer for the founder/avatar presenter. Final Reels are produced through a hybrid workflow:

```
Strategy
→ Script
→ Director brief
→ Valerie scenes in HeyGen
→ Editor assembly
→ B-roll / mockups / screenshots / captions
→ Final Reel
```

The goal is to avoid generic AI presenter content and create a premium growth-intelligence media system.

## 2. Canonical host

Primary host:

**Valerie Petra**

Roles:
- Founder, CAESTHETIC
- CAESTHETIC Growth Advisor

Valerie is a real brand representative. Content must preserve authentic founder positioning. The avatar is used to scale communication, not to create a fictional spokesperson.

## 3. Avatar direction

Character:
- intelligent
- calm authority
- analytical
- approachable
- operator-side advisor
- not influencer-style
- not sales presenter

Speech:
- clear articulation
- deliberate pauses
- emphasized key phrases
- natural American business communication style
- medium expressiveness
- confident but not theatrical

Avoid:
- exaggerated gestures
- generic AI presenter tone
- aggressive sales energy
- fake personal claims

## 6. Editor workflow

HeyGen produces Valerie speaking scenes only.

Editor adds:
- B-roll
- screenshots
- UI mockups
- motion graphics
- subtitles
- pacing
- sound design
- transitions

A Reel should normally not contain the avatar continuously.

## 7. Required visual asset library

Build reusable CAESTHETIC assets:

- Growth Score report mockups
- Four Surface framework graphics
- internal growth workflow diagrams
- Sprint roadmap visuals
- client-facing deliverable examples
- booking journey illustrations
- evidence review examples
- anonymized case-study templates

No fabricated client results, revenue claims, testimonials or performance numbers.

## 8. Reel production package

Every Reel requires:

1. Objective
2. Audience question
3. Hook
4. Spoken script
5. Scene timing
6. Valerie scenes for HeyGen
7. Editor instructions
8. B-roll list
9. On-screen text
10. CTA
