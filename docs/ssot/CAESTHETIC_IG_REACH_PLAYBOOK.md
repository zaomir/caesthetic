# CAESTHETIC IG — reach playbook (audience sees *our* posts)

**Surface:** `@caesthetic.growth` · `B_CAE_IG` · Dolphin `833304152`  
**Parent:** `CAESTHETIC_IG_GROWTH_PROGRAM.md` §10.1 (DEC-824)

Coverage runners make *us* appear in *their* story viewers. This playbook answers the opposite job: **how more of the Phase-1 audience sees our publications** — without blowing write caps.

**Placement + amplification overview (strategy discussion canon):** `docs/ssot/CAESTHETIC_IG_CONTENT_PLACEMENT.md` — use that file first for “what to publish where” and “how to amplify”; this file holds lever detail (50 hooks, collab, paid gates).

## 0. Decisions (locked)

1. **Do not raise outbound follow above 5–8/day** to get more post views. Follow is a scarce close, not a reach lever (DEC-822 / DEC-824).
2. Raise follow only after 7–14 days with **0 action blocks** and follow-back **≥10–12%**, and only to **8–10** — never a blast.
3. **Daily presence = Stories (1–4 frames on weekdays).** Ready week templates: `CAESTHETIC_IG_STORY_TEMPLATES_WEEK.md`. Reel cadence derives from publishable Evidence and Growth Score capacity under Reel System V3, not a fixed daily/weekly quota.
4. **Email carries volume; IG carries familiarity** — `CAESTHETIC_EMAIL_TO_IG.md`.
5. **Forbidden:** bought followers/views, engagement pods, gray boost farms, IG-handle Meta Custom Audiences, second IG on the same Dolphin fingerprint as `833304152`.

## 1. Cadence: Stories vs Reels vs feed video

| Format | Cadence | Job |
|--------|---------|-----|
| **Stories** | Almost every weekday, 1–4 frames | Warm audience sees us; research-desk presence |
| **Reels** | Evidence/capacity-derived | Cold Reach acquisition + Score Intent evergreen library |
| **Feed carousel / static** | As planned in launch grid | Save/share hooks; pins |
| **Feed video (non-Reel)** | Rare | Usually weaker than Reel for discovery |

**Correct understanding:** we need **daily Stories**, not necessarily a brand-new Reel every day. Reels come from the **10-topic FAQ library** (`CAESTHETIC_OWNER_MARKETING_QUESTIONS.md` §8) plus diagnostic reach pieces.

## 2. How to increase each lever

### 2.1 Story-view (on *their* stories) — coverage

- Already: AM/PM timers (`cae_ig_coverage_ops_2026-08-14.md`).
- If day-4 coverage &lt;80% of queue → add a second block the same day; **do not** raise follows.
- Keep 45–90s gaps; stop on challenge.

### 2.2 Like

- Day-1: ~30. After 48h clean: 40–50/day.
- Only when a recent post exists. Bundle with profile open after story pass.

### 2.3 Fact-comment (on *their* posts)

- Fact-gated drafts in coverage runner (`CAE_IG_COMMENT_SEND=0` default).
- Enable send only after human QA of ~10 drafts.
- Cap: 3 → 5–8; Tier A; 10–20+ min after any write; no links; no Score pitch in comment.

### 2.4 Re-share / mention loop (warm → they see *us*)

After follow-back (thanks DM already allowed):

1. Within 24h, post **our** Story featuring their **public** post or a reply to their story.
2. One factual observation; no Score link in that frame.
3. Mention `@them`.
4. Cap **3–5/day**; write gaps 10–20+ min.
5. Automate only after template + approve gate — default is **manual**.

### 2.5 Make touches convert into “saw our post”

- Keep **3 pins** live (growth program §4).
- Fresh feed post **&lt;24–48h** at top of grid when coverage is heavy.
- Highlights named for owners (START / SCORE / …).
- Own Stories every weekday so return visitors see motion.

## 3. Collab Reel / Story with Phase-1 injectors / medspas

Not a cold blast to 1,400.

1. Only Tier A + follow-back or email/IG reply.
2. Ask: permission to feature a **public** post in a research Story / short collab Reel — no hard sell.
3. Offer: free Growth Score or one-leak teardown.
4. Format: use the Reel System V3 class that gives the approved evidence enough
   inspection time; “what we saw across four surfaces” with their OK on facts.
5. Pace: ~1 city / week.
6. Opening must be observation-first, not “let’s collab for reach.”

## 9. Reels vs Stories (definitions)

| | Stories | Reels |
|--|---------|-------|
| Lifespan | ~24h | Long-lived in profile / discovery |
| Who sees | Mostly followers / recent engagers | Can reach non-followers |
| Job | “We are live / research desk” | One thesis + save/share |
| Length | 1–4 short frames | Usually 15–45s |
| Primary CTA | reply / poll / mention | save / share / profile visit |

Use **both**: Stories for daily warm visibility; Reels for library + algorithm.
