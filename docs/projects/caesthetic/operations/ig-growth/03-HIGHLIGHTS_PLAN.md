# Five Highlights — Phase-1 `@caesthetic.growth`

**Audience:** US med-spa / aesthetic practice owners  
**Rules:** evidence-first · no PHI · no student/academy · no Toxifillers SKU · CTA = Growth Score

Cover brief language: Clinical Editorial — cool paper background, IBM Plex / Source Serif feel, one short title, no beauty stock faces.

---

## H1 — Four Surfaces

| Field | Spec |
|-------|------|
| Title | `Surfaces` |
| Cover | Four equal ruled cells labeled Search · Website · Social · Reviews; wordmark CAESTHETIC small |
| Thesis | Patients see one practice across four surfaces — not four separate marketing problems |

**First Story outline (3–4 frames):**

1. Hook: “Your practice doesn’t have four marketing problems.”  
2. Name the four surfaces.  
3. Cross-Surface Consistency sits above them (metric, not a fifth surface).  
4. Sticker CTA: Growth Score · “See which surface is binding.”

---

## H2 — Growth Score

| Field | Spec |
|-------|------|
| Title | `Score` |
| Cover | Simple score card mock with redacted practice name + four surface bars (synthetic demo labeled) |
| Thesis | We diagnose before we pitch — free Growth Score + human walkthrough |

**First Story outline:**

1. “We score aesthetic practices before we pitch them.”  
2. AI gathers/pre-scores; human verifies Class A facts.  
3. Owner outcome: strongest surface, binding constraint, do-not-do.  
4. CTA sticker → `/growth-score/`.

---

## H3 — Leaks

| Field | Spec |
|-------|------|
| Title | `Leaks` |
| Cover | One vertical “leak” diagram: Maps → Website → Social → Reviews with one broken link highlighted |
| Thesis | One observable failure point beats a vague “we need more marketing” |

**First Story outline:**

1. Pick one leak type (example: unanswered reviews / booking friction — public pattern only).  
2. Show what an owner can observe without patient data.  
3. “Don’t buy more traffic yet” if conversion surfaces are broken.  
4. CTA: Get the free Growth Score.

---

## H4 — Sprint

| Field | Spec |
|-------|------|
| Title | `Sprint` |
| Cover | Clean price card: Growth Score $0 → 30-Day Sprint $2,500 → optional Growth System |
| Thesis | Fixed 30 days, no retainer required to start; materials owned by the practice |

**First Story outline:**

1. Ladder: free Score → $2,500 Sprint → optional System.  
2. Sprint = limited implementation across the same four surfaces.  
3. No ranking/patient/revenue guarantees.  
4. CTA: Start with Growth Score (not Checkout hard-sell).

## H5 — Evidence
