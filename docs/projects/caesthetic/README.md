## Charter
CAESTHETIC is the US growth operating system for independent aesthetic practices. The product model is one four-surface system: Search / Website / Social / Reputation.

## Funnel
`Growth Score → Sprint 1 → optional Sprint 2 → optional Growth System`

Only Growth Score, the first 30-Day Growth Sprint and optional Growth System are public product-line concepts. Sprint 2 is an unpublished post-Day-30 finite implementation continuation when justified.
