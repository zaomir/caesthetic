# Expert Dental cross-project contributions

This is the only satellite writeback area for non-PHI Expert Dental project
proposals created from a CAESTHETIC-only workspace.

Allowed: redacted project coordination, implementation proposals, test plans
and decisions that do not change legal wording or runtime authority.

Forbidden: patient records, PHI, secrets, credentials, private client folders,
raw recordings, signed documents, legal-source edits and runtime-source edits.
Legal and runtime work must be implemented in `zaomir/grainee-v2`.
